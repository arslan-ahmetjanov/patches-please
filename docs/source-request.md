# Источник темы: запрос на площадка пилотных запросов

Тема ВКР взята не из головы и не из рабочего проекта, а из открытого запроса корпорации на платформе площадка пилотных запросов. Этот документ фиксирует источник, чтобы в главе 1 и в докладе было чем обосновать актуальность.

## Карточка запроса

| Поле | Значение |
| --- | --- |
| Платформа | площадка пилотных запросов, раздел «Запросы корпораций» |
| Раздел | https://example.invalid/for-startups/pilot |
| Название | Автоматизированная система контроля безопасности разработки (Security Gate) |
| Заказчик | страховая компания |
| Категория | Cybersecurity |
| Дата выгрузки | 21.11.2026 |
| Позиция в выдаче | 1-я при сортировке «Сначала новые» |
| `questionnaireId` | 46049 |
| `pilotId` | 4617281 |

## Текст запроса (цитата)

> Решение для автоматизации контроля информационной безопасности на всех этапах жизненного цикла разработки ПО (CI/CD). Платформа должна интегрироваться в текущие пайплайны, автоматически запускать проверки и блокировать переход релиза на следующий этап при обнаружении критических уязвимостей.

## Как воспроизвести

1. Открыть https://example.invalid/for-startups/pilot.
2. Выбрать сортировку «Сначала новые».
3. Первая карточка — нужный запрос.

Данные выгрузки получены публичным списком:

```
GET https://example.invalid/pilot/list?rowCount=9&pageToken=0&sortBy=created&orderBy=DESC
Заголовки: Client-id: 8385, locale: ru, requestid: <uuid>
```

Полный текст карточки доступен только после входа на платформу: без авторизации открывается предложение создать профиль. Прямая ссылка на карточку не поддерживается — маршрут `/for-startups/pilot/<id>` отдаёт пустую страницу, поэтому ссылаемся на раздел и приводим точные идентификаторы.
