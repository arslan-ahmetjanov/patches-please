# Источник темы: открытый запрос корпорации

Тема ВКР взята не из головы и не из рабочего проекта, а из открытого запроса
корпорации, опубликованного на площадке, где компании ищут исполнителей для
пилотных проектов. Документ фиксирует, что послужило источником, чтобы в главе 1
и в докладе было чем обосновать актуальность.

Названия заказчика и площадки, ссылки и точные идентификаторы карточки в
публичном репозитории не приводятся: для обоснования актуальности нужен сам факт
запроса, а данные организаций в проекте не используются. Карточка сохранена у
автора и может быть показана по запросу.

## Карточка запроса

| Поле | Значение |
| --- | --- |
| Площадка | открытая площадка пилотных запросов корпораций |
| Название запроса | Автоматизированная система контроля безопасности разработки (Security Gate) |
| Отрасль заказчика | крупная страховая компания (название не приводится) |
| Категория | Cybersecurity |
| Дата выгрузки | 21.11.2026 |

## Текст запроса (цитата)

> Решение для автоматизации контроля информационной безопасности на всех этапах жизненного цикла разработки ПО (CI/CD). Платформа должна интегрироваться в текущие пайплайны, автоматически запускать проверки и блокировать переход релиза на следующий этап при обнаружении критических уязвимостей.

## Соответствие запроса и требований спеки

| Формулировка заказчика | Требования |
| --- | --- |
| Интегрироваться в текущие пайплайны CI/CD | FR-019, FR-021 |
| Автоматически запускать проверки | FR-001, FR-002 |
| Блокировать переход релиза на следующий этап | FR-005, FR-020 |
| Контроль ИБ на всех этапах жизненного цикла | FR-014, FR-016, отчёты FR-008 |

## Статус связи

- Тема и границы V1 выведены из этого запроса, ничего сверх него не добавляли.
- Отклик на площадке не отправлялся, пилот не согласован, переписки с заказчиком
  нет.
- Данные заказчика в проекте не используются: демонстрация идёт на собственном
  репозитории.
- Для ВКР запрос — обоснование актуальности, а не внедрение. Формулировка для
  текста: «потребность подтверждена открытым запросом корпорации на площадке
  пилотных проектов».
- Ссылка на карточку, её идентификаторы и скриншот хранятся в личном архиве
  автора: в публичный репозиторий они не выкладываются.
