# Фирменный стиль: Patches, Please

Паспорт стиля для интерфейса и отчётов. Одна страница: что берём, откуда и где
границы. Реализуется внутри T-020, T-022, T-023, T-024 — отдельной задачи на
вёрстку нет.

Если имя продукта изменится, меняется заголовок этого файла и словарь ниже;
идентификаторы контракта и кода от стиля не зависят.

## Название

`Patches, Please` — отсылка к игре Papers, Please: инспектор на границе
пропускает или задерживает документы, а система пропускает или задерживает
патч. Отсылка работает на двух уровнях: кто играл — услышит, кто не играл —
прочитает буквально.

Запятая живёт только в отображаемом имени. Везде в идентификаторах — дефис:
репозиторий и образы `patches-please`, очередь `patches-please`, пакет
`patches_please`, БД `patches_please`, cookie `pp_session`, префикс токена
`pp_`.

## Три слоя, а не три стиля

Смешивать источники в одном экране нельзя. Каждый отвечает за свой уровень.

| Слой | Источник | За что отвечает | Где виден |
| --- | --- | --- | --- |
| Каркас | Papers, Please | структура, метафора досмотра, штамп, тон документа | все страницы, отчёт |
| Техника | Matrix | моноширинный шрифт и тёмный блок только для кода и логов | сниппет находки, лог прогона |
| Тон | Mr. Robot | сухая микрокопия без корпоративного сиропа | подписи, пустые состояния, CHANGELOG |

Правило: **один экран — один слой плюс максимум один островок другого**. Страница
прогона — бумажный документ, внутри которого лежит тёмная распечатка лога.

## Токены

| Роль | Значение |
| --- | --- |
| Бумага (фон) | `#FAF7F0` |
| Чернила (текст) | `#14120F` |
| Приглушённый текст | `#6E665A` |
| Линии и рамки | `#D8D1C2` |
| Штамп «пропущен» | `#1F6B3D` |
| Штамп «задержан» | `#B3261E` |
| Терминал: фон | `#0C120C` |
| Терминал: текст | `#B9F6C1` |
| Терминал: акцент (только статус) | `#7AE582` |

Тёмная тема целиком не делается. Зелёное на чёрном — только внутри терминального
блока, не дальше.

## Типографика

| Шрифт | Кириллица | Применение | Ограничение |
| --- | --- | --- | --- |
| Pixelify Sans | есть | заголовки, логотип, цифры штампа | только от 14px и выше |
| IBM Plex Sans | есть | тело текста, таблицы, формы | — |
| JetBrains Mono | есть | пути, `rule_id`, сниппеты, лог, JSON | — |
| Press Start 2P | есть | только логотип | вдвое шире, живёт на сетке 8px |
| VT323, Silkscreen | **нет** | не использовать | кириллицы нет |

Пиксельный шрифт никогда не попадает в тело текста и в таблицу находок: в отчёте
бывает несколько сотен строк, и читаемость важнее стиля.

## Словарь интерфейса

В API и в спеке остаются `scan`, `pass`, `fail`, `finding`, `baseline`,
`exception`. В интерфейсе — свои слова. Контракт от этого не меняется.

| В API и спеке | В интерфейсе |
| --- | --- |
| прогон (scan) | **досмотр** |
| `pass` | **Пропущен** |
| `fail` | **Задержан** |
| finding | **нарушение** |
| baseline | **опись** |
| exception | **разрешение** (со сроком) |
| `degraded` | **досмотр неполный** |
| очередь прогонов | **очередь** |
| отчёт | **дело** |

Микрокопия сухая. Не «Добро пожаловать в систему!», а «Дел нет», «Очередь
пуста», «Задержано: 3 нарушения, из них 1 критическое».

## Компоненты

- **Штамп.** Прямоугольник с рамкой в 2px, внутри — вердикт и дата, поворот
  −8°. Крупно, в углу шапки отчёта и страницы прогона. Один и тот же элемент в
  HTML и в приложении ВКР.
- **Шапка дела.** Проект, коммит, ветка, время начала и окончания, провайдер.
  Моноширинным — только хеш коммита.
- **Опись нарушений.** Таблица: severity, правило, путь, строка, состояние,
  сканер. Сниппет раскрывается в терминальном блоке.
- **Терминальный блок.** Тёмный, `JetBrains Mono`, зелёный только на статусе
  сканера (`ok`, `degraded`, `error`).
- **Тренд.** Простая линия по прогонам, без заливок и градиентов; цвета — только
  из палитры штампов.
- **Логотип и favicon.** Пиксельный штамп на сетке 16×16 (favicon) и 32×32
  (логотип в шапке), без текста внутри: «P» из Pixelify Sans в рамке штампа.
  Векторную копию не делаем — при увеличении используется штамп, а не логотип.

## Чего не делаем

| Нельзя | Почему |
| --- | --- |
| Маска из Mr. Robot | это дизайн маски Гая Фокса из «V for Vendetta», чужая интеллектуальная собственность |
| Арт, орёл, шрифты и палитра Papers, Please | то же: стилизация допустима, копирование ассетов — нет |
| Фразы вида «Glory to Arstotzka» | прямой перенос вымышленного мира в диплом |
| «Цифровой дождь», глитч на всех страницах | клише, мешает читать отчёт |
| Пиксельный шрифт в теле текста | нечитаемо на 300 находках |
| Тёмная тема целиком | зелёное на чёрном убивает таблицы |

## Где это живёт

`templates/` — Jinja2, стили в одном файле `templates/static/brand.css`.
Скриншоты для ВКР — со страницы прогона (штамп и опись) и со страницы проекта
(тренд). Слайд «О названии» в докладе: штамп из игры рядом с нашим штампом, две
строки объяснения, ссылка на эту страницу.
