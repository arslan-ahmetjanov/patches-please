## Проект

Patches, Please — автоматизированный контроль безопасности разработки для
CI/CD: сканеры → единая модель находок → политика → вердикт `pass`/`fail` →
блокировка пайплайна. ВКР (09.03.03, УГНТУ).
Remote: `arslan-ahmetjanov/patches-please`, ветка `main`.

Стек: Python 3.12, FastAPI, SQLAlchemy 2.0 + Alembic, PostgreSQL 16,
Redis 7.2 + RQ, Jinja2 + HTMX, Docker Compose; pytest, ruff, mypy strict,
uv 0.13.9. Пакет — `patches_please/` (шаблоны и миграции внутри пакета,
T-035).

## Окружение этой машины (проверено)

- Shell — `cmd.exe`. Кавычки в аргументах ломаются: `git commit -m "текст"`
  разбивается на пути — сообщение писать в файл и делать `git commit -F файл`.
  По той же причине не работают `gh run view --log > "%TEMP%\x.log"` и
  `findstr` по логу: путь в кавычках превращается в отдельные аргументы.
  Обход — редирект в файл без кавычек (`> ci_run.log`) и поиск через `rg`.
- `tail` в cmd.exe отсутствует; `&&` после редиректа съедает команду —
  использовать `&`.
- Консоль отдаёт вывод в cp866: кириллица в логах Alembic выглядит
  кракозябрами, это не ошибка.
- Docker Desktop останавливает движок при простое: `docker desktop start`
  поднимает его без прав администратора; служба `com.docker.service` требует
  админа (иначе ошибка 5). Стек после старта поднимается сам
  (`restart: unless-stopped`), тома сохраняются. Признак остановленного
  движка — `open //./pipe/dockerDesktopLinuxEngine: The system cannot find the
  file specified` у `docker compose ps` и `connection timeout` у psycopg
  к `localhost:5432`, хотя контейнеры были healthy минуту назад.
- Порт 8000 попадает в зарезервированный диапазон Windows 7979–8078, поэтому
  в `.env` стоит `API_PORT=8081`.
- Тома `pgdata`/`redisdata`/`reportsdata` не удалять: `docker compose down`
  только без `-v` и только в каталоге проекта.
- Рядом работают контейнеры чужого проекта `crm-*` — не трогать.
- После хронометража T-033 тома очищены: данных T-029/T-030 в БД и отчётов нет,
  цифры в `docs/measurements.md` сохранены; замеры воспроизводятся скриптами
  `scripts/measure_scan.py` и `tests/load/k6.js` (нужен k6 и токен проекта).

  в находках они маскируются при нормализации.
- Одна задача — один коммит, Conventional Commits на русском; push, amend и
  переписывание истории — только по просьбе.
- Код и спека расходятся — остановиться и спросить, а не подгонять спеку.
