Remote: `arslan-ahmetjanov/patches-please`, ветка `main`.

Стек: Python 3.12, FastAPI, SQLAlchemy 2.0 + Alembic, PostgreSQL 16,
Redis 7.2 + RQ, Jinja2, Docker Compose; pytest, ruff, mypy strict, uv 0.13.x.

## Окружение этой машины (проверено)

- Shell — `cmd.exe`, и он вырезает кавычки и `$` из аргументов: `git commit -m
  "текст"` разбивается на пути. Сообщение писать в файл и делать `git commit
  -F файл`; переменные PowerShell задавать не через `-Command`, а скриптом.
- PowerShell 5.1 читает `.ps1` в системной кодировке: кириллица внутри скрипта
  ломает разбор. Служебные скрипты писать ASCII-текстом, русский вывод
  направлять в файл и читать файлом, а не из консоли.
- Консоль отдаёт вывод в cp866; `rg` в PATH нет (используется поиск внутри
  агента), `tail` отсутствует, `&&` после редиректа съедает команду — `&`.
- Docker Desktop останавливает движок при простое: `docker desktop start`
  поднимает его без прав администратора. После старта `docker compose ps`
  несколько секунд может показывать контейнеры без проброса портов — это не
  ошибка конфигурации, надо подождать. Признак остановленного движка —
  `open //./pipe/dockerDesktopLinuxEngine` у `docker compose ps` и
  `connection timeout` у psycopg к `localhost:5432`.
- Порт 8000 попадает в зарезервированный диапазон Windows 7979–8078, поэтому
  в `.env` стоит `API_PORT=8081`; клиенту нужен `--server` или
  `PATCHES_PLEASE_URL`.
- Тома `pgdata`/`redisdata`/`reportsdata` не удалять: `docker compose down`
  только без `-v` и только в каталоге проекта.
- Рядом работают контейнеры чужого проекта `crm-*` — не трогать.
- Демо-стенд заполнен, baseline стоит: при повторном запуске
  `scripts/seed_demo.py` токен не пересоздаётся, новый выдаётся с
  `--rotate-token`.

## Границы

- Поведение системы, контракты (`contracts/openapi.yaml`,
  `contracts/report.schema.json`), схема БД, зависимости и CI-шаблоны — только
  после согласования. Контракты генерируются скриптами `scripts/export_*`,
  руками не правятся.
- Секреты, пароли и открытые токены не попадают в репозиторий, логи и отчёты;
  в находках они маскируются при нормализации.
- Одна задача — один коммит, Conventional Commits на русском; push, amend и
  переписывание истории — только по просьбе.
- Правка `demo/` требует повторной публикации демо-репозитория: источник
  правды — каталог `demo/`, а не ручные правки на GitHub.
- Код и спека расходятся — остановиться и спросить, а не подгонять спеку.
