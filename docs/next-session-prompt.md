## Проект

Проект Patches, Please отвечает за автоматизированный контроль безопасности
разработки для CI/CD: сканеры → единая модель находок → политика → вердикт
`pass`/`fail` → блокировка пайплайна. ВКР (09.03.03, УГНТУ).
Remote: `arslan-ahmetjanov/patches-please`, ветка `main`.

Стек: Python 3.12, FastAPI, SQLAlchemy 2.0 + Alembic, PostgreSQL 16,
Redis 7.2 + RQ, Jinja2, Docker Compose; pytest, ruff, mypy strict, uv 0.13.x.
Пакет: `patches_please/` (шаблоны и миграции внутри пакета, T-035).

## Что осталось

Обязательных задач V1 нет. Открытые шаги:

1. **Публичный адрес стенда для `demo-scan.yml`.** Переменная
   `PATCHES_PLEASE_URL` удалена: из этой сети туннели не поднимаются, а мёртвый
   адрес даёт загадочный `502`. Проверено: Cloudflare quick tunnel не
   регистрируется (ни в контейнере, ни нативно), `bore.pub:7835` недоступен,
   `serveo.net` отдаёт `502`, `pinggy` и `localhost.run` показывают ссылку
   только в интерактивном TUI. Нужен развёрнутый стенд или туннель, который
   работает из этой сети; после этого выполнить `gh variable set PATCHES_PLEASE_URL` и
   `gh workflow run demo-scan.yml`. Секрет `PATCHES_PLEASE_TOKEN` уже задан.
2. **Скриншоты для ВКР**: снять при видимом окне приложения.

Перед показом:

- если стенд использовался для демонстрации, сменить пароль демо-пользователя и
  выпустить новый токен `ci` (`--rotate-token`), а не пользоваться прежним;
- сверить число находок Trivy с фактическим отчётом: база зашита в образ при
  сборке и дрейфует, поэтому для демо важно наличие трёх классов находок, а не их число;
- при правке `demo/` переопубликовать демо-репозиторий: источник правды
  лежит в каталоге `demo/`, ссылка на опубликованную копию уже есть в `README.md`.

## Окружение этой машины (проверено)

- Shell `cmd.exe` вырезает кавычки и `$` из аргументов: `git commit -m
  "текст"` разбивается на пути. Сообщение писать в файл и делать `git commit
  -F файл`; переменные PowerShell задавать не через `-Command`, а скриптом.
- PowerShell 5.1 читает `.ps1` в системной кодировке: кириллица внутри скрипта
  ломает разбор. Служебные скрипты писать ASCII-текстом, русский вывод
  направлять в файл и читать файлом, а не из консоли.
- Консоль отдаёт вывод в cp866; `rg` в PATH нет (используется поиск внутри
  агента), `tail` отсутствует, `&&` после редиректа съедает команду, нужен `&`.
- Docker Desktop останавливает движок при простое: `docker desktop start`
  поднимает его без прав администратора. После старта `docker compose ps`
  несколько секунд может показывать контейнеры без проброса портов, это не
  ошибка конфигурации, надо подождать. Признак остановленного движка:
  `open //./pipe/dockerDesktopLinuxEngine` у `docker compose ps` и
  `connection timeout` у psycopg к `localhost:5432`.
- Туннели наружу из этой сети почти не работают: Cloudflare quick tunnel не
  регистрируется (ошибка `Register tunnel ... context deadline exceeded`, и в
  контейнере, и нативным `cloudflared.exe`), `bore.pub:7835` недоступен,
  `serveo.net` поднимает ссылку, но отдаёт `502`, `pinggy` и `localhost.run`
  печатают адрес только в интерактивном TUI. Для проверки интеграции нужен
  развёрнутый стенд с публичным адресом.
- `gh run watch ... & echo exit=%ERRORLEVEL%` в `cmd.exe` печатает старое
  значение: `%ERRORLEVEL%` раскрывается до запуска. Проверять результат по
  логу run-а или отдельной командой.
- Порт 8000 попадает в зарезервированный диапазон Windows 7979–8078, поэтому
  в `.env` стоит `API_PORT=8081`; клиенту нужен `--server` или
  `PATCHES_PLEASE_URL`.
- Тома `pgdata`/`redisdata`/`reportsdata` не удалять: `docker compose down`
  только без `-v` и только в каталоге проекта.
- Рядом работают контейнеры чужого проекта `crm-*`, их не трогать.
- Демо-стенд заполнен, baseline стоит: при повторном запуске
  `scripts/seed_demo.py` токен не пересоздаётся, новый выдаётся с
  `--rotate-token`.

## Границы

- Поведение системы, контракты (`contracts/openapi.yaml`,
  `contracts/report.schema.json`), схему БД, зависимости и CI-шаблоны меняем только
  после согласования. Контракты генерируются скриптами `scripts/export_*`,
  руками не правятся.
- Секреты, пароли и открытые токены не попадают в репозиторий, логи и отчёты;
  в находках они маскируются при нормализации.
- Каждая задача в отдельном коммите, Conventional Commits на русском; push, amend и
  переписывание истории только по просьбе.
- Правка `demo/` требует повторной публикации демо-репозитория: источник
  правды это каталог `demo/`, а не ручные правки на GitHub.
- Если код и спека расходятся, остановиться и спросить, а не подгонять спеку.
